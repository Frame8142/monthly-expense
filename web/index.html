เดือนนี้ยังไม่มีรายการ

กดปุ่มด้านล่างเพื่อลอกชื่อ+ยอดจากเดือนล่าสุดมา (แบบ ก.) แล้วค่อยแก้ยอดนิดหน่อย

💡 วิธีใช้: แก้ยอดในช่องตัวเลขได้เลย (บันทึกอัตโนมัติ) → ติ๊ก ✅ เมื่อจ่ายแล้วแถวจะเขียว → ยอดบนสุดขยับทันที → เดือนใหม่กด “ลอกเดือนที่แล้วมา”

🧾 รายการหลัก (ล่าสุด)

ชื่อที่จำไว้ใช้ลอกเดือนหน้า เพิ่ม/แก้/ซ่อนตรงนี้ มีผลกับเดือนหน้า ไม่ลบประวัติเดือนเก่า

❓ ใช้ยังไง (สั้นๆ)

  1. ขึ้นเดือนใหม่ → กด ลอกเดือนที่แล้วมา
  2. แก้ยอดที่เปลี่ยนในช่องตัวเลข
  3. จ่ายรายการไหน → ติ๊ก ✅ แถวเขียว
  4. มีบิลใหม่ → กด ＋ เพิ่มรายการ
  5. ชื่อผิด → กด ✏️ ในแถวนั้น
เก็บข้อมูลใน Google Sheet ของคุณ · เปิดเว็บนี้บนคอมได้เลย ไม่ต้องติดตั้ง

＋ เพิ่มรายการใน

จะเพิ่มทั้งในเดือนนี้ + จำในรายการหลักให้เดือนหน้าลอกไปด้วย

✏️ แก้ชื่อรายการ
